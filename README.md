# BVH2MMD 0.3.0-rc1

BVHと対象モデルのPMXから、体格に合わせた30fpsのVMDを生成するWindows向け実験版です。独立アプリで、MotionBuilder・Blender・MMD本体のインストールは変換処理に不要です。

通常の利用はWindows ZIPをすべて展開してBVH2MMD.exeを起動し、GUIDE.txtまたは「はじめに.txt」に沿って操作してください。元のBVH・PMXは変更しません。

## ソースから起動

Python 3.12以上（Tkを含む）で、このフォルダーを作業場所にして実行します。

```console
python -m pip install -r requirements.txt
python app.py
python -m unittest discover -s . -p "test_*.py" -v
```

テストには人工BVHとテスト中に生成する合成PMXを使います。実モデルや収録モーションは不要です。

## 対応と制約

標準MMD脚構成と平らな静止床向け。ボーン対応と座標系を指定し、脚長から倍率を推定します。安定した足の接地区間を補正し、FKとして書き出します。出力ではモデルのIKをオフにします。
指・表情・髪・衣装の物理、階段・移動床・逆関節、特殊な脚構造は対象外です。短い接地や回転中の足は固定を控えます。任意のモデルへの適合を保証しません。

既存検証はWindows 11 / MMD 9.32 x64の1モデル・1テイクが対象。6213フレームの全編再生と数値検査、抽出421コマの目視を実施済みです。全コマ連続目視、別PC・別モデルの確認は未実施です。

このr2はライセンスと公開説明を補完したパッケージ改訂で、数値処理は0.3.0-rc1のまま、画面文言を更新して再ビルドしています。画面と説明書の表記を配布版に統一しました。
